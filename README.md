# Panel Vital — Kalkulator Kesehatan

Kalkulator kesehatan interaktif dengan tampilan bertema instrument panel / monitor vital. Tiga kanal kalkulasi, semua hitung langsung tanpa reload halaman.

## Fitur
- **Kanal BMI** — indeks massa tubuh + kategori (kurus/normal/kelebihan berat/obesitas) dengan gauge visual
- **Kanal Kalori** — estimasi kebutuhan kalori harian (TDEE) pakai rumus Mifflin-St Jeor
- **Kanal H2O** — estimasi kebutuhan air minum harian berdasarkan berat badan dan aktivitas

## Cara pakai
Buka `index.html` langsung di browser — tidak perlu instalasi atau server, murni HTML/CSS/JS vanilla.

## Deploy ke GitHub Pages
1. Push repo ini ke GitHub
2. Buka **Settings → Pages**
3. Pilih branch `main` dan folder `/ (root)`
4. Situs akan aktif di `https://<username>.github.io/<nama-repo>/`

## Disclaimer
Semua hasil hitungan bersifat estimasi umum, bukan pengganti konsultasi tenaga medis profesional.
